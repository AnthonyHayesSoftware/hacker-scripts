Video Promotion Pilot — Settings

Transcripts are grabbed straight from the YouTube page (free, no setup). Everything below is stored only in this browser profile.

Brand profiles

Create one profile per brand you publish for. Each can carry a written style description and/or a Project URL (a ChatGPT or Claude Project whose files already hold your brand identity). Pick which one to use from the side panel before generating an infographic.

Tip for clients: generate a sample infographic in ChatGPT, then ask ChatGPT to "write a reusable brand style description from this image" and paste it below — or save it into a ChatGPT Project and paste the Project's URL instead. If you set a Project URL, leave the description blank and the project handles the look. With no Project URL, the description is injected and you can attach a sample image in the chat yourself.

Call-to-action snippets

Save the CTAs you reuse (in your own words) — a workshop, a lead magnet, a newsletter signup. Pick one from the side panel and it's woven into the close of the content you generate. You can switch CTA per generation.

AI app destinations (defaults)

Fallback targets used when a brand has no Project URL for that app. Leave blank to use the public defaults.

Decodo fallback (advanced, off by default)

An optional paid transcript API used only if in-page extraction fails. Left off for most users — the in-page method covers captioned videos.

Saved transcripts

Transcripts are cached per video so switching tabs is instant. Clear them to force a fresh grab (this also happens automatically on every update).

Backup & restore

Loading a fresh unzipped build is a new extension to Chrome, so it starts with empty settings. Export your brand profiles, CTAs and URLs to a file, then Import it into any future build (or another machine) to get everything back in one click. Tip: export again whenever you change something, and keep the file somewhere safe.

Everything here is stored in chrome.storage.sync on this browser profile only — never committed to a repo or sent anywhere except the services you point it at.
