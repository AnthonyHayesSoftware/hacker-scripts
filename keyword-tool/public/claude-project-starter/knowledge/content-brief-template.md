# Content brief format

Produce every brief in this structure before writing the article.

```
# Content brief: [Working title]

- Primary keyword: [keyword]
- Secondary / cluster keywords: [comma-separated]
- Search intent: [informational | commercial | transactional | navigational]
- Target reader: [who, and what they want to achieve]
- Funnel stage: [awareness | consideration | decision]
- Suggested H1 / title (≤60 chars): [title]
- Meta description (≤155 chars): [description]
- URL slug: [slug]
- Target length: [word range, justified by the SERP/competitors]

## Outline
- H2: [section] — covers keyword(s): [...]
  - H3: [subsection]
- H2: [section] — covers keyword(s): [...]
...

## Questions to answer (snippets & AI Overviews)
- [Q] → [1–2 sentence standalone answer]
- [Q] → [answer]

## Entities & topics to include
- [entity / concept], [entity / concept], ...

## Internal links to include
- [anchor] → [/url]

## Notes
- [intent traps to avoid, angle, unique value vs. competitors]
```

Keep briefs tight and decision-ready: every line should help the writer or the
editor, not restate the obvious.
